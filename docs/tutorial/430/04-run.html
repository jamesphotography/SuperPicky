执行选鸟 Running a Cull

4.1

选择目录 Selecting a Folder

向 SuperPicky 慧眼选鸟 指定照片来源有三种方式，效果完全相同，选最顺手的即可： There are three ways to tell SuperPicky 慧眼选鸟 where your photos are. All three are equivalent — use whichever feels most natural:

  • 01 点击「浏览」按钮 → 在弹出的文件选择框中找到目标文件夹，点击「选择」确认 Click the Browse button → navigate to the target folder in the file picker and click Select
  • 02 直接键入或粘贴路径 → 在路径输入框中输入完整路径后按 Enter 键确认 Type or paste the path → enter the full path in the directory input field and press Enter
  • 03 拖放文件夹 → 从 Finder（macOS）或资源管理器（Windows）将目标文件夹直接拖入路径输入框 Drag and drop → drag the target folder from Finder (macOS) or Explorer (Windows) onto the directory input field

选好目录后，软件会自动做一次预检： After a folder is loaded, SuperPicky 慧眼选鸟 runs a quick pre-check:

预检结果Pre-check result 界面反应UI response
首次处理（无历史记录） First time (no history) 日志区显示「准备就绪」，「开始处理」按钮激活 Log shows "Ready", the Start button activates
已有处理历史（有上次报告） Previously processed (report found) 底部出现历史提示条，「重置」按钮激活，可选择继续查看或重新处理 A history banner appears at the bottom, the Reset button activates — you can view previous results or re-run
小提示：用最近目录快速加载 Tip: Quick-load from Recent Folders

常用目录可以从菜单栏「最近目录」直接点击加载，省去每次重新浏览的步骤。详见第 02 章 2.3。 Frequently used folders can be loaded with one click from the Recent Folders menu, saving you from browsing every time. See Chapter 02, Section 2.3.

4.2

递归批处理 Recursive Batch Mode

SuperPicky 慧眼选鸟 会在你选择目录后自动判断是单目录还是批量模式，无需手动切换。 SuperPicky 慧眼选鸟 automatically detects whether to run in single-folder or batch mode — there is no manual switch to flip.

软件扫描所选目录及其子目录（最多 16 层），找出所有原子目录——即直接包含照片文件的目录。扫描时自动排除 SuperPicky 慧眼选鸟 自身产生的输出目录（星级目录、burst_xxx、隐藏目录等）。 SuperPicky 慧眼选鸟 scans the selected folder and all subdirectories (up to 16 levels deep), locating every atomic directory — a folder that directly contains photo files. It automatically skips its own output directories (star-rating folders, burst_xxx, hidden folders, etc.).

扫描结果Scan result 处理方式Processing mode
只找到 1 个含照片的目录 Only 1 directory with photos found 单目录模式，直接处理 Single-folder mode — processes immediately
找到 2 个及以上含照片的目录 2 or more directories with photos found 批量模式，逐目录串行处理，各自生成独立报告 Batch mode — processes each folder in sequence, each generates its own report

批量模式的日志特征： Batch mode log markers:

📂 Batch mode: 5 directories detected ───────────────────────────────────────────────── 📁 [1/5] 2025-11-01/ (312 photos) ... 处理中 / processing ... 📁 [2/5] 2025-11-02/ (204 photos) ... 处理中 / processing ... ───────────────────────────────────────────────── 📊 Batch complete: 5 dirs, 1024 photos, 287s
典型使用场景 Typical Use Case

出行时按日期建立了多个子文件夹（如 2025-11-01/、2025-11-02/）——选最外层父目录即可，SuperPicky 慧眼选鸟 会自动逐个处理所有子目录，最终汇总摘要。 Shot over multiple days with date-named subfolders (e.g. 2025-11-01/, 2025-11-02/)? Select the parent folder — SuperPicky 慧眼选鸟 processes each subfolder automatically and aggregates the final summary.

4.3

读懂日志 Reading the Log

日志区的每一行都有颜色和图标，让你快速区分处理状态： Each log line uses color and icons to let you parse processing status at a glance:

颜色 / 图标Color / Icon 含义Meaning 典型内容Typical content
✅ 绿色 成功 Success 发现鸟、评星完成、处理成功 Bird detected, rating assigned, processing done
⚠️ 橙色 警告 Warning 文件跳过、无法处理、非致命问题 File skipped, unreadable file, non-fatal issue
❌ 红色 未检测到鸟 / 错误 No bird / Error 未检测到鸟（不影响其他文件继续处理），或单文件处理异常 No bird detected (other files continue normally), or a single-file processing error
默认色 信息 Info 进度计数、计时、扫描结果等 Progress counter, timing, scan results

每张照片的典型日志序列： Typical log sequence per photo:

[1/500] 处理: DSC01234.ARW ✅ 发现鸟！置信度: 87% ⭐⭐⭐ 优选照片 (AI:0.87, 锐度:450.2, 美学:5.24) [2/500] 处理: DSC01235.ARW ✅ 发现鸟！置信度: 72% ⭐⭐ 良好照片 (AI:0.72, 锐度:390.8, 美学:4.95) [3/500] 处理: DSC01236.ARW ✅ 发现鸟！置信度: 68% ⭐ 普通照片 (AI:0.68, 锐度:410.1, 美学:4.21) [4/500] 处理: DSC01237.ARW ✅ 发现鸟！置信度: 91% 0⭐ 质量差: 锐度太低 (210.3 < 380) [5/500] 处理: DSC01238.ARW ❌ 未检测到鸟

括号内评分含义： Score breakdown in brackets:

  • AI YOLO 检测置信度（0–1），数值越高表示 AI 越确定画面中有鸟 YOLO detection confidence (0–1) — higher means the AI is more certain there is a bird
  • 锐度 鸟头区域锐度评分，与你在参数区设置的锐度阈值进行比较（见第 03 章 3.2） Head-area sharpness score — compared against your sharpness threshold (see Chapter 03, Section 3.2)
  • 美学 TOPIQ 美学评分，综合构图、曝光与色彩，与美学阈值比较（见第 03 章 3.3） TOPIQ aesthetics score — composition, exposure, and color combined, compared against your aesthetics threshold (see Chapter 03, Section 3.3)

其他常见日志行： Other common log lines:

🔄 开始并行转换 48 个RAW文件（8线程）... RAW 文件在 AI 推理前自动完成并行解码 RAW files are decoded in parallel before AI inference ☕ 已启动防休眠保护 (macOS only) 处理期间系统不会自动休眠 System sleep is suppressed during processing
4.4

完成摘要 Completion Summary

处理结束后，日志区会自动追加一份统计报告： When processing finishes, a statistics report is automatically appended to the log:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 处理报告 / Processing Report ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 共 500 张照片 总耗时 142s (2.4min) 平均 0.28s/张 Total: 500 photos · 142s (2.4min) · 0.28s/photo avg ⭐⭐⭐ 87 (17.4%) └─ 🏆 23 (26% of 3★) ⭐⭐ 156 (31.2%) ⭐ 89 (17.8%) 0⭐ 51 (10.2%) ❌ 117 (23.4%) 识别鸟种 / Species identified: 白腹海雕 / White-bellied Sea Eagle · 大白鹭 / Great Egret · ... ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

各行含义： What each line means:

  • ⭐⭐⭐ 三星精品数量：锐度和美学双达标的照片，是选片的核心输出 3-star count: photos that passed both the sharpness and aesthetics thresholds — your primary culling output
  • 🏆 三星中的「Pick 精选」：美学排名靠前的一批（占三星总数的百分比），即软件认为最值得优先后期的照片；详见第 05 章 The "Pick" selection among 3-star photos — the top-ranked shots by aesthetics score (shown as % of 3★). These are the photos SuperPicky 慧眼选鸟 considers most worth prioritising in post; details in Chapter 05
  • ⭐⭐ / ⭐ 二星和一星数量：锐度达标但美学分较低（二星），或锐度未达标（一星） 2-star and 1-star counts: sharp but lower aesthetics (2★), or below sharpness threshold (1★)
  • 0⭐ 零星废片：有检测到鸟，但锐度严重不足的照片 0-star rejects: bird detected but sharpness well below threshold
  • ❌ 未检测到鸟：不等于废片，可能是有鸟但置信度未达标，或画面内容本身不包含鸟 No bird detected: does not necessarily mean bad photos — the bird may have been below confidence threshold, or the frame may simply not contain a bird
  • 鸟种 本次处理中识别出的所有鸟种列表（仅开启「识鸟」开关时显示，见第 03 章 3.6） All species identified during this cull (only shown when the Bird ID toggle is on — see Chapter 03, Section 3.6)

报告完成后，日志区还会自动追加一段 Lightroom 导入指引，说明如何通过文件夹导入并用星级筛选已选片，详见第 05 章。 After the report, the log appends a Lightroom import guide explaining how to import by folder and filter by star rating. Full details in Chapter 05.

与此同时，窗口底部状态条切换为精简摘要：完成！N 张 ★★★ N ★★ N ★ N，方便快速查看整体结果而无需滚动日志。「查看结果」按钮也同步激活（见第 02 章 2.2），点击即可进入结果浏览器。 Simultaneously, the status bar at the bottom switches to a compact summary: Done! N photos ★★★ N ★★ N ★ N — no need to scroll the log. The View Results button also activates (see Chapter 02, Section 2.2), taking you straight to the Result Browser.
