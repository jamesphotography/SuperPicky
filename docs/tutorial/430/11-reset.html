重置与重新处理

改变参数后想重跑？处理到一半中断了？选错目录了？ 本章解释 SuperPicky 慧眼选鸟 的两种恢复操作——重置和重新处理—— 以及出现历史提示弹窗时该如何选择。

11.1何时需要重置或重新处理 11.2重新处理（调参后快速重跑） 11.3完整重置（清除所有记录） 11.4历史目录提示弹窗
11.1

何时需要重置或重新处理

选鸟完成后，SuperPicky 慧眼选鸟 将照片分散到各个子目录，并在隐藏目录 .superpicky/ 中记录处理结果。 如需再次处理同一目录，必须先把文件归位，否则程序看到的目录已不是原始状态。

以下场景需要重新处理或重置：

重新处理（推荐）
  • 修改了锐度 / 美学阈值，想用新参数重跑
  • 开启或关闭飞版 / 连拍 / 曝光检测
  • 更换摄影水平预设
  • 修改了精选百分比或连拍阈值
  • 修改了目录布局（鸟种优先 ↔ 星级优先）
  • 修改了元数据写入模式或 ARW 策略
完整重置
  • 想彻底清除所有评分，还原到未处理状态
  • EXIF 数据写错，希望完全清空后重来
  • 目录将被其他软件使用，需要干净的原始文件
  • 确认不再需要任何历史处理记录
两者的核心区别

重新处理跳过 EXIF 清除步骤（旧评分会被新结果直接覆盖）、保留 .superpicky/ 缓存目录（预览图可复用，速度更快），适合参数调整后的迭代。

完整重置额外清除文件中的 EXIF 评分字段，并删除 .superpicky/ 目录，让目录恢复到完全未处理的状态。

11.2

重新处理（调参后快速重跑）

已处理目录在主界面会显示「重新处理」按钮（位于开始按钮左侧）。 点击后，SuperPicky 慧眼选鸟 自动执行快速复原再重新处理，全程无需手动干预：

0
清理连拍子目录 — 将连拍组的「最佳帧」子目录中的文件归还到各自的连拍组目录
1
文件归位 — 将散布在各星级 / 鸟种子目录中的所有照片和视频移动回根目录，恢复原始平铺结构
—
跳过 EXIF 清除（快速模式）— 旧评分仍留在文件中，重新处理后会被新结果直接覆盖，无需提前清空
3
清理空目录 — 删除归位后遗留的空子目录，保持根目录整洁
▶
立即开始新一轮选鸟 — 复原完成后自动以当前参数重新处理，.superpicky/ 缓存保留以复用预览图
在点击前先调好参数

点击「重新处理」会立即触发快速复原 + 重新处理，中间没有二次确认。 请确保在点击前已在主界面或高级设置中调整好所有参数。

11.3

完整重置（清除所有记录）

若需彻底清除评分并还原原始文件，在已处理目录的状态下点击主界面的「重置」按钮， 确认弹窗后执行以下完整流程：

0
清理连拍子目录 — 同重新处理，先归还连拍组内的最佳帧文件
1
文件归位 — 将所有文件移回根目录，删除空子目录
2
清除 EXIF 评分字段 — 使用 ExifTool 将文件中的星级（XMP:Rating）、 鸟种名、Pick 旗标等 SuperPicky 写入的元数据字段全部清空
3
清理空目录 — 删除遗留的空文件夹
完
删除 .superpicky/ 目录 — 清除预览图、数据库（report.db）及 manifest， 目录恢复为完全未处理的初始状态
此操作不可撤销

完整重置会修改文件的 EXIF 元数据并删除处理记录，无法通过软件内的操作撤销。 若只是要调参重跑，建议优先使用重新处理（11.2），保留现有评分数据更安全。

重置完成后，主界面恢复为「未处理」状态，「开始选鸟」按钮可用， 可以选择新参数重新开始处理。

11.4

历史目录提示弹窗

当你选择的目录存在未完成的处理记录时（例如上次处理途中强制退出、 电脑崩溃或手动停止），SuperPicky 慧眼选鸟 会在你点击「开始选鸟」时弹出提示：

发现未完成的处理记录
这个目录存在未完成的处理记录。选择「继续处理」会从上次中断的位置继续；选择「重新开始」会先恢复目录，再重新处理。
继续处理 重新开始
选项 行为 适用场景
继续处理 从上次中断的位置恢复，跳过已完成的文件，沿用上次的参数 意外中断后想尽快完成；参数没有变化
重新开始 先执行快速复原（等同于「重新处理」），再以当前参数重新处理全部文件 中断前参数有误；想用新参数完整重跑
「已处理完成」的目录不会弹窗

只有检测到中途中断的目录才会触发此弹窗。 正常完成处理的目录选中后，按钮直接变为「重新处理」，点击即可快速重跑，不会再弹窗询问。

存储卡上处理的风险

若目录位于 SD 卡或其他可移动磁盘上，选择目录时会额外弹出警告。 选鸟过程需要移动大量文件，存储卡读写慢且文件系统脆弱—— 中途断电、拔卡或卡满都可能导致照片分散在子目录中无法自动归位。 强烈建议先将照片复制到电脑硬盘，再进行选鸟。
