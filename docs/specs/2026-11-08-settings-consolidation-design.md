# 设置中心整合为 4 页 + 脱焦封顶（#158）设计

日期：2026-11-08　状态：已实施
Date: 2026-11-08　Status: implemented

## 1. 为什么做 / Why

**设置太散，用户分不清。** 设置中心现有 7 页（精选 / 识鸟 / 输出 / 视频 / 外部应用 / 实验室 / 关于），约 45 项，按「属于哪个模块」划分，而不是按「用户需不需要懂」划分。新手打开「精选」页，档位旁边就是 V1 回退开关；打开「输出」页，前三项全是元数据写入方式的细节。用户每天真正会碰的不到十项。

**#158：脱焦糊片拿了 3 星。** Al（Canon R5m2，ISO 1600，1/400）的一张追焦糊片冠蓝鸦，头部锐度 484，被评为 3★，详情面板同时显示「Out of Focus」（对焦点在鸟外）。原因有两层：

1. 锐度算法（`core/keypoint_detector.py` `_calculate_sharpness`，头部圆 ∩ 分割掩码上的 Tenengrad）量的是边缘陡度，深色鸟头衬亮天空的轮廓、嘴里浅色的花生都会让糊片得高分。这是已知弱点（见 sharpness-eval v1 的 `sp_bad_scored_high.jpg`），**本次不改算法**。
2. V2 评星里有一处自相矛盾：对焦仲裁（`FOCUS_ARBITRATION_SHARPNESS = 520`）的含义是「相机判脱焦，且鸟头实测锐度不到 520，就认定确实脱焦」。但认定脱焦后，V2 只扣 0.06 分（`PENALTY_FOCUS_WORST`），恰好被飞鸟加分 +0.06 抵消，照片仍能凭批内名次拿 3★。

## 2. 目标 / 非目标 / 反目标

**目标**
- 设置中心改为 **常用 / 高级 / 实验室 / 关于** 4 页；新手只看「常用」就够用。
- 视频功能移入实验室并默认关闭（「不稳定的功能」此处只指视频；无鸟补救扫描等其他功能的默认值不变）。
- V2 评星：被认定脱焦的照片最多 2★；判定锐度线（默认 520）在高级页可调。

**非目标**
- 不改锐度算法本身（等 v2 多机型标注集再说；σ 组合方案已于 2026-10-04 否决）。
- 不动首页参数面板（档位标签、飞鸟/连拍/识鸟开关、配额条或 V1 滑块，维持现状）。
- 不改 V1 评星（V1 的仲裁线继续跟随用户锐度滑块，对焦权重直接乘进锐度，本来就会压分）。
- 不往菜单栏添加新的设置开关。

**反目标（即使能用也算失败）**
- 同一项设置出现在比现在更多的地方。
- 升级后一部分老用户的视频处理突然停了，或者没开过的人被默默打开。
- 任何设置在搬家后读写的配置字段变了，导致老用户的值丢失或回到默认。
- 「恢复默认」后重建页面时，旧值被写回。

## 4. 页面内容 / Page contents

已在浏览器示意图中给用户看过（`.superpowers/brainstorm/…/settings-4pages.html`）。

### ① 常用（common）
- **选片**：摄影水平（技能档位选择）、飞鸟检测、连拍检测
- **识鸟**：自动识别鸟种、国家 / 地区（含「编辑…」）、鸟名显示格式
- **整理与提示**：分类目录布局、播放完成提示音、删除照片前确认

### ② 高级（advanced）——按原模块分小节，小节可折叠
- **评星**（默认展开）：星级配额分配条（V2）、**脱焦判定锐度线（新）**、使用旧版 V1 评星（及 V1 锐度/美学滑块，保留现有切换确认对话框）、AI 置信度、连拍速度、无鸟补救扫描、处理的文件格式
- **识鸟**：识别置信度、数据源（eBird / 全球）、英文命名标准、自定义罕见指数（导入）
- **输出与元数据**：元数据写入方式、专有 RAW 也写入文件本体、写入哪些字段（含一键精简/全部勾选）、连拍归入独立子文件夹、为 0 星和无鸟照片补充详情面板数值
- **外部应用**：应用列表（添加/删除）、关闭主窗口时
- **存储**：保留预览图片、清理所有预览缓存

### ③ 实验室（labs）
- **更多功能**：生成报告、导出到 eBird（不变）
- **实验功能**：多目录选鸟（不变）、**分析照片时同时处理视频**（搬入）；视频开关打开后才显示其子选项：识别模式、抽帧上限、YOLO 置信度、启用鸟种识别、启用飞行/停栖检测

### ④ 关于（about）
内容不变：版本、检查更新、开发者/致谢/数据来源、发送匿名使用统计、恢复默认设置…（确认框里罗列的页面名需同步改成新页名）。

## 5. 关键机制 / Key mechanics

### 5.1 设置项搬家不换字段
每一项设置在新页面上**读写原来的 `advanced_config` 字段**，字段名、默认值、setter 的 clamp 范围全部不变。这次只是控件换位置，不是数据迁移。

### 5.2 视频开关：复用 `video_auto_process_in_main`，不新增 `lab_*` 字段
- 实验室页的「分析照片时同时处理视频」直接绑定现有的 `video_auto_process_in_main`（默认值已经是 `False`）。
- 这样 D2 自动成立：开过的老用户字段是 `True`，继续生效；其余用户是 `False`，保持关闭。**不需要迁移，也就不存在两个开关不一致的可能**（4.5.0 的事故正是开关与守卫分离造成的）。
- 这偏离了 CLAUDE.md「实验室新功能用 `lab_*` 开关」的约定；理由是视频不是新功能，已有一个字段在守卫主流程，再加一个 `lab_video` 必须迁移且两个字段要同时判断。**这是我的取舍**，需在 CLAUDE.md 的实验室约定里补一句例外说明。
- 主流程守卫（`ui/main_window.py` 约 264 行）不变。
- 日志 `logs.video_skipped_disabled`（「可在『设置 → 视频』中开启」）三语改为指向「设置 → 实验室」。
- **删除首次发现视频时的一次性提示**（用户拍板 D8）：删掉 `_maybe_prompt_video_first_run` 及其两处调用（`ui/main_window.py` 约 3199、3573 行）和三语文案 `dialogs.video_first_tip_title` / `dialogs.video_first_tip_body`（若无其他引用）。配置字段 `video_first_run_prompted` 随之无人读取，从 `DEFAULT_CONFIG` 与 `PRESERVE_ON_RESET` 中一并移除；老配置文件里残留的这个键会被忽略，无害——**这是我的取舍**。

### 5.3 脱焦判定锐度线
- 新增配置字段 `v2_focus_arbitration_sharpness`，默认 `520`，setter clamp **300–800**，UI 控件（滑块或步进框）范围与步长 10 与之一致。下限 300 是因为低于 3★ 兜底线后封顶没有意义；上限 800 是我的取值，留给锐度整体偏高的机型。
- 它是用户设置，**不进** `PRESERVE_ON_RESET`。
- `core/photo_processor.py`（约 2968 行）V2 分支的仲裁阈值从常量 `FOCUS_ARBITRATION_SHARPNESS` 改为读这个配置；常量保留作为默认值的唯一来源（`DEFAULT_CONFIG` 引用它，避免两处写 520）。V1 分支不变。
- **封顶规则**（`core/rating_quota.py` `assign_ratings_v2`，配额定星循环内、眼睛封顶之后、连拍封顶之前）：`focus_status == "WORST"` 且星级 > 2 → 降为 2★，`reason_key = "rating_v2.focus_capped"`。
  - 进入 V2 排序池的 `focus_status` 已经是仲裁之后的结果（`photo_processor` 由仲裁后的权重推出），所以「WORST」就等于「相机判在鸟外，且锐度没过判定线」，封顶规则本身不需要再比较锐度。
  - 只对 `WORST`（对焦点在鸟框外）封顶，不对 `BAD`（在框内但不在鸟身上）封顶——**这是我的取舍**：BAD 的判定离鸟更近、更可能是记录偏差，先保守；与 V2 现有只对 WORST 扣分的口径一致。
  - **降级不递补**——**这是我的取舍**：被封顶空出的 3★ 名额不顺延给组内下一名，与现有的锐度兜底、眼睛封顶、连拍封顶完全同一口径（`SKILL_QUOTA3` 注释已写明配额是「上限而非实得比例」）。所以只有 1–2 张的鸟种，若唯一的 3★ 候选是脱焦片，该鸟种就没有 3★——这正是本修复要的结果；鸟种保底仍保证它至少有一张 2★。
  - `compute_q` 中的 `PENALTY_FOCUS_WORST` 保留（影响 2★/1★ 之间的排序）。
  - 鸟种保底（`apply_species_floor`）在其后执行，不受影响：被封顶的照片仍是 2★，不会让某鸟种掉到 2★ 以下。
- 题注（`core/rating_caption.py`）：`rating_v2.focus_capped` 加入 `RANKED_OUTCOMES` 与原因映射，新增三语文案，句式对齐 `why_eye_capped`，例如「为什么不是 3★：{place}，名次够 3★，但相机对焦点在鸟外、鸟头锐度不足以推翻，最多给 2★」。详情面板/星级原因的短文案（`eye_capped` 同级）也加一条。
- `FOCUS_ARBITRATION_SHARPNESS` 的现有测试（`tests/test_rating_quota.py` 约 299 行，锁 520 与实拍复核一致）保留，改为断言默认配置值等于该常量。

### 5.4 页面键与入口
- `PAGE_ORDER = ["common", "advanced", "labs", "about"]`。
- `_open_settings_center(start_page)` 的现有调用：`"culling"`（菜单「设置中心」、首页档位标签）→ `"common"`；`"birdid"`（开始处理前「改国家」、识鸟国家提示，共 3 处）→ `"common"`（国家/地区在常用页）；`"about"` 不变。建议对旧键做一层兼容映射，避免漏改的调用打开错页。
- 设置中心导航栏底部的语言选择器（`_build_language_picker`）移除；菜单「设置 → 语言」不变。
- 关闭设置中心后照旧调用 `_refresh_skill_chip()` + `_refresh_param_panel()`；「恢复默认」后照旧 `_rebuild_pages()`。
