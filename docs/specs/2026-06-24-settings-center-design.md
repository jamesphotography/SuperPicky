# 设置中心(Settings Center)重组设计

- 日期 / Date: 2026-06-24
- 状态 / Status: 设计已确认,待评审
- 分支建议 / Branch: 实施时基于 `dev` 新开 `feat/settings-center`

## 1. 背景与问题 / Background

当前设置/菜单的信息架构混乱,用户确认的四个痛点全部命中:

1. **同类设置分散多处** —— 精选参数在主窗口参数面板和高级设置对话框各有一份;识鸟设置散在三处(主窗口开关、高级设置识鸟 tab、识鸟停靠面板的国家/区域)。
2. **入口太多太杂** —— 菜单 / 参数面板 / 识鸟面板 / 多个弹窗,找一个设置不知道去哪。
3. **菜单组织不合理** —— 设置菜单只 2 项、帮助菜单只 1 项,而大量设置其实埋在面板与对话框里,分类失衡。
4. **弹窗层级深/多** —— 高级设置 5 个 tab 的弹窗,技能等级又是另一个弹窗,嵌套深、来回切。

数据层是混乱的根:同一设置存在三套存储 —— 运行时拼装的 `ui_settings` 数组、`advanced_config.json`(主持久化)、`birdid_dock_settings.json`(识鸟国家/区域)。

## 2. 目标 / Goals

- 所有设置收敛到**单一「设置中心」窗口**,左侧分类导航 + 右侧内容,心智模型唯一:"所有设置都在设置中心"。
- **取消主窗口参数面板**(用户确认:这些参数一次调好、很少动)。
- **技能等级与精选阈值在同一页协同**,关系直观(技能等级 = 阈值的快捷预设)。
- **识鸟设置三处合一**。
- **数据层单一事实源**:统一到 `advanced_config`,消除"同一设置多处存"。
- 图标统一用 SVG(与近期 UI 去 emoji 方向一致),不使用 emoji。

## 3. 非目标 / Non-Goals (YAGNI)

- 不重新设计处理算法或参数语义,仅迁移其入口与存储。
- 不做设置项的增删(除技能等级整合、识鸟合并外,保持现有项不变)。
- 不引入云同步/多 profile 等新能力。

## 4. 方案:统一设置中心 / Chosen Approach

新建 `ui/settings_center.py` 的 `SettingsCenter(QDialog)`:左侧 `QListWidget` 分类导航 + 右侧 `QStackedWidget` 内容页。取代现有 `advanced_settings_dialog`(QTabWidget)、`skill_level_dialog`、`about_dialog` 的独立入口(其内容/组件迁移复用)。


### 4.3 现有内容 → 新分类映射

| 新分类 | 收纳内容(来源) |
|--------|------------------|
| **精选** | 技能等级预设档(置顶)← 合并 `skill_level_dialog`;AI 置信度、清晰度(锐度)、画面美感(NIMA)、飞行/连拍检测 + 连拍速度 ← 合并主窗口参数面板 + 高级设置"精选"页 |
| **识鸟** | 自动识鸟开关、识别确信度、数据源(eBird/GBIF)、国家、区域 ← 合并三处(参数面板开关 + 高级设置识鸟页 + 识鸟面板国家/区域) |
| **输出** | 保存裁剪、归一化模式、分目录布局、XMP 元数据、预览 ← 参数面板 + 高级设置"输出"页 |
| **视频** | 视频处理开关、识别模式、抽帧上限、YOLO 阈值、检测开关 ← 高级设置"视频"页(原样迁移) |
| **外部应用** | 外部编辑器列表(右键"用…打开")← 高级设置"应用"页(原样迁移) |
| **关于** | 版本、致谢、链接 ← 合并 `about_dialog` |

注:曝光检测已移除(固定 False)、保存裁剪现固定 True,迁移时保持现状。

### 4.4 「精选」页 —— 技能等级与阈值协同(关键交互)

```
┌─ 精选 ───────────────────────────────────────┐
│  技能等级(预设)                              │
│   ( )入门  (•)进阶  ( )专业  ( )大师  ( )自定义 │
│   提示:选预设自动填下方阈值;手动改阈值→自动转"自定义" │
│  ────────────────────────────────────────── │
│  AI 置信度      [======•======]  0.25         │
│  清晰度(锐度)   [========•====]  380          │
│  画面美感(NIMA) [=====•=======]  4.8          │
│  ────────────────────────────────────────── │
│  检测项                                       │
│   [✓] 飞行检测   [✓] 连拍检测   连拍速度 [10] fps │
└───────────────────────────────────────────────┘
```

交互规则:
- 选预设档 → 用 `core.skill_presets.get_skill_level_thresholds` 自动填三个阈值滑块。
- 用户手动改任一阈值 → 档位自动切换到"自定义"。
- 复用 `core.skill_presets`(无 Qt 依赖)做档↔阈值换算;复用 `skill_level_dialog` 现有卡片组件渲染档位。

### 4.5 「识鸟」页

```
┌─ 识鸟 ──────────────────────────────────┐
│  [✓] 处理时自动识别鸟种                   │
│  ──────────────────────────────────────  │
│  识别确信度   [======•======]  (现值)     │
│  ──────────────────────────────────────  │
│  地区过滤(提高准确率)                    │
│   数据源:  (•) eBird   ( ) GBIF          │
│   国家:    [ 自动检测(GPS)        ▾ ]     │
│   区域:    [ 整个国家             ▾ ]     │
└──────────────────────────────────────────┘
```

识鸟停靠面板(`birdid_dock`)**只保留运行时操作**(选图/截图/结果展示),移除国家/区域/开关配置控件,新增一个"设置"小链接 → 打开设置中心并定位到识鸟页。

### 4.6 主窗口变化

- **取消参数面板** `_create_parameters_section`,主界面只剩:目录选择 + 开始处理 + 结果区。
- **菜单简化**:移除"设置菜单(高级设置/技能等级)"与"帮助菜单(关于)"的分散项,改为单一齿轮「设置」按钮/菜单项 → 打开设置中心(关于、技能等级都在其中)。
- **header 技能等级 chip**:保留只读 chip 显示当前档,点击 → 打开设置中心"精选"页。

## 5. 数据层统一 / Data Layer (单一事实源)

**采用选项 1:`advanced_config` 作为单一事实源(SSOT)。**

- 设置中心所有读写走 `advanced_config`。
- 将原参数面板的值(AI 置信度、锐度、NIMA、飞行、连拍、归一化)纳入 `advanced_config` 持久化字段。
- 识鸟国家/区域/数据源从 `birdid_dock_settings.json` **一次性兼容迁移**进 `advanced_config`:首次启动检测旧文件存在且新字段为空时搬运,旧文件保留不删作备份。
- 处理流程:`main_window` 启动处理时直接从 `advanced_config` 读值拼 `ProcessingSettings`(取代从参数面板控件读 `ui_settings`)。`ui_settings` 数组形态可保留为内部传参,但其值来源改为 `advanced_config`。

迁移函数需幂等、跨平台、UTF-8 安全(国家/区域含中文)。

## 6. 受影响文件 / Affected Files

- 新增 `ui/settings_center.py` —— `SettingsCenter` 主体(左侧导航 + stacked pages)。
- `ui/advanced_settings_dialog.py` —— 现有 5 个 `_create_*_page` 逻辑迁移/复用进设置中心;该对话框入口废弃。
- `ui/skill_level_dialog.py` —— 卡片组件复用进"精选"页;独立对话框入口废弃。
- `ui/about_dialog.py` —— 内容迁入"关于"页;独立入口废弃。
- `ui/birdid_dock.py` —— 移除配置控件,新增跳转设置中心的"设置"链接;国家/区域读取改自 `advanced_config`。
- `ui/main_window.py` —— 删参数面板、改菜单为单一「设置」入口、header chip 跳转、`ui_settings` 取值改自 `advanced_config`。
- `advanced_config.py` —— 扩展字段(精选阈值/检测开关/归一化/识鸟国家区域) + 一次性迁移逻辑。
- `locales/zh_CN.json` / `locales/en_US.json` —— 新增设置中心文案,清理废弃入口文案。

## 7. 验证 / Verification

- 改动 Python 文件 `py_compile` 通过;`zh/en` JSON 合法。
- 数据迁移:构造含中文国家/区域的旧 `birdid_dock_settings.json`,验证首次启动正确搬运进 `advanced_config` 且读回一致(UTF-8)。
- 端到端:设置中心改值 → 关闭重开持久化保留 → 启动处理时 `ProcessingSettings` 取到新值。
- 技能等级协同:选预设填阈值、改阈值转"自定义"两条交互验证。
- 识鸟三处合一:设置中心改国家/区域 → 识鸟面板与主处理一致取到。
- 回归:跨平台(Windows + macOS)启动冒烟,确认无旧入口残留报错。

## 8. 风险 / Risks

- 数据迁移影响旧用户配置 —— 以"旧文件保留 + 幂等迁移"降险。
- 改动面大(7 个文件)—— 实施按"设置中心骨架 → 各页迁移 → 主窗口接线 → 数据层迁移 → 清理旧入口"分步,每步可独立验证。
